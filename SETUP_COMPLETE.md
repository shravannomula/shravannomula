## 🚀 READY TO USE - QUICK COMMANDS

### Frontend Project

```bash
# Clone
git clone https://github.com/shravannomula/developer-toolkit.git
cd developer-toolkit

# Development
pnpm install
pnpm dev

# Build
pnpm build

# Docker
docker build -t developer-toolkit:latest .
docker run -p 8080:80 developer-toolkit:latest

# Deploy to Vercel
vercel --prod
```

### Backend Project

```bash
# Clone
git clone https://github.com/shravannomula/toolkit-api-backend.git
cd toolkit-api-backend

# Development
npm install
cp .env.example .env
docker-compose up -d
npm run start:dev

# Build
npm run build

# Docker
docker build -f Dockerfile -t toolkit-api:latest .
docker-compose up -d

# Kubernetes
kubectl create namespace toolkit
kubectl apply -f k8s/ -n toolkit
```
